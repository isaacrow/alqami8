# Enrolment photos for recognition by sight

ALQAMI recognises a Moon record's cover automatically. For objects, manuscripts or anything without a cover, add
photos here and the next deploy (or the nightly run) puts them in the recognition index.

- One folder per object, named after what it should open, with `__` in place of `:`
  - `moon__<record id>` opens that Moon record (for example `moon__sample-9780394740676`)
  - `artifact__<ALQAMI id>` opens a built-in object (for example `artifact__ALQ-HLM-004`)
- 5 or more photos per object, from the sides visitors will see it, in the light of the hall, JPEG or PNG.
- Keep each photo under about 1 MB (1600 px on the long side is plenty).

The photos from an Object Capture session work well here too.
